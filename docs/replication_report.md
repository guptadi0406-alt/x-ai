# Replication Report

## Paper Objective

Salih et al. (2024) present a perspective on SHAP and LIME, two widely used XAI methods, discussing their working mechanisms, strengths, weaknesses, and particularly their behavior in the presence of:
1. **Model dependency** — different ML models produce different feature importance rankings
2. **Feature collinearity** — correlated features affect the reliability of XAI outputs

The paper includes two case studies:
- **Case Study 1 (UK Biobank, Section 2):** Classification of myocardial infarction using 10 features and 1500 subjects. We do NOT replicate this due to restricted data access.
- **Case Study 2 (Airline Satisfaction, Section 3):** Classification of passenger satisfaction using 22 features and 500 subjects. This is our primary replication target.

## Dataset and Preprocessing

- **Source:** Kaggle Airline Passenger Satisfaction dataset
- **Paper specification:** 500 subjects, 250 satisfied, 22 features, 80/20 split
- **Our approach:** Stratified random sampling from the full dataset with seed=42
- **Limitation:** The paper does not disclose the exact sampling seed or procedure

### Preprocessing Steps
1. Categorical encoding (LabelEncoder fitted on training data only)
2. Numerical scaling (StandardScaler fitted on training data only)
3. Missing value handling (median for numerical, mode for categorical)
4. No target leakage: all transformations fitted on training split only

## Model and XAI Implementations

| Component | Paper | Our Implementation |
|-----------|-------|--------------------|
| Decision Tree | sklearn default | `DecisionTreeClassifier(random_state=42)` |
| Logistic Regression | sklearn default | `LogisticRegression(max_iter=1000, random_state=42)` |
| LightGBM | default | `LGBMClassifier(random_state=42, verbose=-1)` |
| SVC | default | `SVC(probability=True, random_state=42)` |
| SHAP | Library version not specified | `shap 0.49.1` with model-appropriate explainers |
| LIME | Library version not specified | `lime 0.2.0.1` |
| NMR | Custom (GitHub) | Reimplemented from paper description and README |
| MIP | Custom (GitHub) | Reimplemented from paper description and README |

## Main Replicated Results

### Classifier Performance
The paper reports approximate accuracies (Table 2):
- LGBM: 0.91, LR: 0.85, DT: 0.84, SVC: 0.86

Our results are generated by running the pipeline and saved in `results/tables/classifier_performance.csv`.

### SHAP Feature Rankings
The paper shows different feature rankings across models (Table 2), demonstrating model dependency. Our replication generates the same type of comparison in `results/tables/shap_ranking_comparison.csv`.

### NMR Values
Paper-reported NMR values: LGBM=0.231, LR=0.275, DT=0.445, SVC=0.273.
Our computed values are in `results/tables/nmr_comparison.csv`.

### MIP Rankings
The paper shows SHAP vs MIP adjusted rankings (Table 3) for LGBM. Our comparison is in `results/tables/shap_vs_mip.csv`.

## Reproducibility Challenges

1. **Unknown sampling procedure:** The paper's 500-subject sample cannot be exactly reproduced without the original seed.
2. **NMR/MIP implementation details:** The original source code was only partially available as README examples. Full algorithm details were inferred from the papers.
3. **SHAP version differences:** Different SHAP versions may produce slightly different results due to internal implementation changes.
4. **Default parameters:** "Default parameters" can differ across library versions.

## Differences and Limitations

- Our sample is an approximation of the paper's 500-subject subset
- NMR and MIP implementations may differ from the original in edge cases
- SVC uses KernelSHAP (computationally expensive approximation)
- Results should be interpreted as an approximate reproduction
